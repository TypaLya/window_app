# Window App — система планирования производства стеклопакетов

Десктопное приложение на Python для управления производственными заказами, оптимизации раскроя дистанционной рамки и стекла, а также учета складских материалов.

Приложение объединяет основные инструменты подготовки заказов и планирования производственных операций в одном графическом интерфейсе.

## Возможности

### 1. Раскрой дистанционной рамки
- Формирование списка стеклопакетов на основе производственных заказов.
- Расчет длин элементов рамки с учетом технологического резерва.
- Группировка деталей по профилям заданной длины.
- Построение и визуализация карт раскроя.
- Просмотр состава каждой карты раскроя.

### 2. Раскрой стекла
- Подготовка карт раскроя для стеклянных листов.
- Настройка размеров исходного листа.
- Выбор режима оптимизации: быстрый, комбинированный или глубокий перебор.
- Настройка порога заполнения листа.
- Визуализация результатов раскроя.

Для размещения прямоугольных заготовок используется библиотека `rectpack`.

### 3. Планирование производства
- Создание и ведение производственных заказов.
- Хранение информации о заказчике, сроках, приоритете и статусе заказа.
- Добавление стеклопакетов и материалов в заказ.
- Импорт данных заказов из файлов Excel форматов `.xls` и `.xlsx`.

### 4. Складской учет
- Раздельный учет материалов по категориям: комплектующие, пленка, оконные материалы, триплекс, основное стекло и материалы участка резки.
- Хранение сведений об остатках, приходе, расходе, резерве, стоимости и движении материалов.
- Загрузка складских данных из Excel-файлов.
- Просмотр складских позиций в табличном виде.

## Технологии

- **Python** — основной язык разработки.
- **Tkinter / CustomTkinter** — графический интерфейс.
- **SQLite** — локальное хранение данных.
- **NumPy** — вспомогательные вычисления.
- **rectpack** — алгоритмы двумерной упаковки для раскроя стекла.
- **OpenPyXL / xlrd** — чтение Excel-файлов.
- **ezdxf** — работа с файлами формата DXF.

## Установка и запуск

### Требования

- Python 3.10 или новее.
- Windows рекомендуется для запуска графического приложения; на других ОС работа Tkinter зависит от установленной системной версии Tcl/Tk.

### 1. Клонирование репозитория

```bash
git clone https://github.com/TypaLya/window_app.git
cd window_app
```

### 2. Создание виртуального окружения

Windows:

```bash
python -m venv .venv
.venv\\Scripts\\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python main.py
```

При первом запуске функция `create_database()` создает необходимые таблицы в SQLite-базе `orders.db`, если их еще нет.

## Данные и файлы

- База данных SQLite создается в рабочем каталоге приложения.
- Перед обновлением или удалением `orders.db` рекомендуется сделать резервную копию: в ней могут храниться производственные заказы и складские данные.
- Для импорта складских ведомостей приложение ожидает Excel-файлы в каталоге `warehouse_table/`. Названия и расположение файлов должны соответствовать путям, указанным в `warehouse.py`.
- Для импорта производственных заказов доступны форматы `.xls` и `.xlsx`.

## Авторизация и безопасность

В текущей версии учетные записи определены непосредственно в `Users.py` и хранятся в памяти приложения. В коде предусмотрены демонстрационные учетные данные:

| Логин | Пароль |
|---|---|
| `admin` | `admin` |
| `user` | `password` |

Это демонстрационные данные для разработки. Перед использованием приложения в реальной рабочей среде замените их и реализуйте безопасное постоянное хранение учетных записей. Не используйте текущую схему авторизации для защиты производственных или конфиденциальных данных.
